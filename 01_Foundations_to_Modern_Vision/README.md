# Part I — Foundations to Modern Vision

Modules **00–31** form the first complete course in the repository.

```text
ML foundations
→ tensors / optimization / autograd
→ CNNs and training
→ modern CNN / Transformer backbones
→ detection / segmentation / pose
→ contrastive and self-supervised representation learning
→ foundation backbones
→ PEFT / LoRA
→ distillation / pruning / quantization
```

## Learning layers

Part I has two complementary layers:

1. **Mechanics modules** in this directory — deterministic examples, first-principles math, PyTorch references, C++17 native counterparts, and parity.
2. **Applied Labs** in [../applied_labs](../applied_labs) — optional real-data training, checkpoints, held-out metrics, and runtime evidence.

See the repository [course roadmap](../COURSE_ROADMAP.md) and [Part-I review](../STAGE1_REVIEW.md).
