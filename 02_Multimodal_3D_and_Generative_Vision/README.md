# Part II — Multimodal, 3D and Generative Vision

**Planned modules: 32–60.**

This part will cover:

- image/text embeddings and zero-shot classification
- captioning, VQA and multimodal reasoning
- open-vocabulary detection and grounding
- multimodal retrieval and visual agents
- video understanding and tracking
- learned depth and 3D representations
- NeRF, Gaussian Splatting and neural rendering
- autoencoders, diffusion, flow matching and video generation

Module folders will be added only when implementation begins; the repository does not pre-create dozens of empty lesson directories.

See [COURSE_ROADMAP.md](../COURSE_ROADMAP.md) for the detailed sequence.
